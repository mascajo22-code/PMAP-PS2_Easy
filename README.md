# PMAP-# PMAP Easy – PlayStation 2 Mechacon Tool

**PMAP Easy** est un projet visant à simplifier l'utilisation de PMAP pour le diagnostic et les réglages des lecteurs optiques de la PlayStation 2.

L'objectif est de proposer une interface graphique Windows simple, intuitive et accessible aux réparateurs de consoles, avec un minimum de manipulations.

## ✨ Fonctionnalités prévues

- Interface graphique simplifiée.
- Utilisation du moteur PMAP original.
- Détection et sélection du port COM.
- Communication avec une interface USB-UART compatible.
- Accès aux fonctions de diagnostic Mechacon.
- Fonctions de lecture et sauvegarde EEPROM.
- Mesures et diagnostic du jitter.
- Assistance aux réglages électriques du lecteur.
- Génération d'un rapport de diagnostic.
- Mode d'emploi inclus.

## 🖥️ Compatibilité

- Windows 7
- Windows 8 / 8.1
- Windows 10
- Windows 11

## 🎯 Objectif du projet

Rendre les opérations de diagnostic et de maintenance des lecteurs PlayStation 2 plus simples, notamment pour les personnes qui ne maîtrisent pas toutes les commandes de PMAP.

Le projet privilégie une utilisation simplifiée avec un bouton principal de lancement du diagnostic et des opérations guidées.

## ⚠️ Avertissement

Ce logiciel est destiné aux utilisateurs ayant des connaissances en réparation électronique.

Les réglages du laser et du Mechacon peuvent endommager le matériel s'ils sont effectués incorrectement. Les mesures doivent être vérifiées avant toute modification.

Un réglage automatique ne garantit pas une réparation parfaite.

# PMAP-# PMAP Easy – PlayStation 2 Mechacon Tool

**PMAP Easy** is a project designed to simplify the use of PMAP for diagnosing and adjusting PlayStation 2 optical disc drives.

The goal is to provide a simple, intuitive Windows graphical interface for console repair technicians, requiring minimal manual input.

## ✨ Planned Features

- Simplified graphical user interface.
- Utilizes the original PMAP engine.
- COM port detection and selection.
- Communication via a compatible USB-UART interface.
- Access to Mechacon diagnostic functions.
- EEPROM read and backup capabilities.
- Jitter measurement and diagnostics.
- Assistance with electrical adjustments for the optical drive.
- Generation of diagnostic reports.
- User manual included.

## 🖥️ Compatibility

- Windows 7
- Windows 8 / 8.1
- Windows 10
- Windows 11

## 🎯 Project Objective

To streamline diagnostic and maintenance tasks for PlayStation 2 optical drives, specifically for those who may not be familiar with all the individual PMAP commands.

The project focuses on ease of use, featuring a primary button to launch diagnostics and providing guided, step-by-step operations.

## ⚠️ Warning

This software is intended for users with experience in electronic repair.

Improper adjustment of the laser or Mechacon settings can damage the hardware. Always verify measurements before making any changes.

Automatic adjustment does not guarantee a perfect repair.
